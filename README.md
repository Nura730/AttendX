# 🎓 AttendX

Smart Attendance & GPA Tracker built with React Native and Expo.

## Features

### 📚 Attendance Management

- Add subjects
- Mark attendance
- Attendance history
- Attendance percentage calculation
- Safe/Danger status
- Bunk calculator

### 📊 Analytics Dashboard

- Overall attendance tracking
- Subject comparison charts
- Attendance insights
- Attendance prediction
- Attendance streak tracking

### 🎓 GPA Calculator

- SGPA calculation
- Credit-based grading
- Grade point conversion
- GPA prediction

### ⚙️ Settings

- Attendance target management
- Data management
- App preferences

## Tech Stack

### Frontend

- React Native
- Expo
- TypeScript

### State Management

- Zustand
- AsyncStorage

### Navigation

- React Navigation

### Charts

- react-native-chart-kit
- react-native-svg

## Installation

```bash
git clone https://github.com/YOUR_USERNAME/AttendX.git

cd AttendX

npm install

npx expo start
```
